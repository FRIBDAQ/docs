<a name="l00133"></a>  133         {


<a name="l00134"></a>  134             // Because ranges are semi inclusive { i.e. [beg,end) }, we


<a name="l00135"></a>  135             // already have all of the information needed to update the


<a name="l00136"></a>  136             // sum. The end is currently "out-of-range" but will become


<a name="l00137"></a>  137             // the newest in-range value once the range in incremented.


<a name="l00138"></a>  138             // The value pointed to by begin will not be in the range any


<a name="l00139"></a>  139             // more once incremented.

<a name="l00141"></a>  141             T old_end_val = *(m_range.end());


<a name="l00142"></a>  142
