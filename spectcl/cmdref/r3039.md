# <a name="ref.startcommand"></a>start

<a name="AEN3043"></a>## Name

start -- Start analyzing data

<a name="AEN3046"></a>## Synopsis

**start1
            **

<a name="AEN3049"></a>## DESCRIPTION

Starts analyzing data from the current data source.  Data will be
            analyzed until one of the following occurs:



- The **stop** command is issued.
- The **attach** command attaches SpecTcl
                      to a new data source.
- An endfile is encountered on the current data source.
