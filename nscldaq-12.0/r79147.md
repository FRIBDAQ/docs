# <a name="py3.person"></a>LogBook.Person

<a name="AEN79151"></a>## Name

LogBook.Person -- Python class encapsulating Log Book people.

<a name="AEN79154"></a>## Synopsis

```

PYTHONPATH=$DAQROOT/pythonLibs/nscldaq python3

import LogBook.LogBook as LogBook
...
book = LogBook.LogBook('logbookfile.log')
person = book.get_person(1)
      
```

```

id    = person.id
last  = person.lastname
first = person.firstname
sal   = person.salutation


      
```

<a name="AEN79158"></a>## DESCRIPTION

`LogBook.Person` is a python class that wraps
            instances of persons in the logbook database
            [*LogBook*](https://github.com/FRIBDAQ/docs/tree/main/nscldaq-12.0/r78727.md)
            provides methods that produce `LogBook.Person`
            objects, or tuples of them.

A `LogBook.Person` object should be thought of
            as a container with several read-only attributes. These are:



- Integer` id`
  The primary key associated with that person.
- String` lastname`
  The last name of the encapsulated person.
- string` firstname`
  The given (first) name of the encapsulated person.
- String` salutation`
  The salutation for the encapsulated person.
