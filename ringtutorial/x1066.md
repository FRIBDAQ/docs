# <a name="AEN1066"></a>3.5. Modifying the Makefile

Finally any code in addition to Skeleton.cpp
                needs to be compiled and linked into the final Readout program.
                This is done by modifying the OBJECTS
Makefile macro.  For our example, assuming we
                have been porting files named MyEventSegment.{cpp,h}
                and MyScaler.{cpp,h}, this means we'll have
                a line that look like:

<a name="AEN1075"></a>```
OBJECTS=Skeleton.o MyEventSegment.o MyScaler.o
                
```
