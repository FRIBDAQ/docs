<a name="details"></a>## Detailed Description


### template<class T>  

struct TrAnal::CFDResult< T >


Result for a [CFD](https://github.com/FRIBDAQ/docs/tree/main/ddas-1.1/classCFD.md) computation.


Together the two items in this struct locate the zero crossing.


Because the [CFD](https://github.com/FRIBDAQ/docs/tree/main/ddas-1.1/classCFD.md) algorithm does not necessarily start its search at the beginning of the search, it can only identify a location. Typically, the trig and the fraction will be used in a manner similar to as follows.

```
... code ...

// Execute CFD algorithm over first 100 elements of trace
CFDResult<uint16_t> res = CFD(  TrRange<uint16_t>(trace.begin(),100), //range to search
                                10, // fast filter rise
                                2,  // fast filter gap 
                                3,  // cfd delay
                                0 );  // cfd scale factor

// Compute distance from start of trace to res.trig and then add fraction
double cfd_zero_crossing = (res.trig - trace.begin()) + fraction;

... code ...
```
