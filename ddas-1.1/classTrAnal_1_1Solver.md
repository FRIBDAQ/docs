<a name="details"></a>## Detailed Description


Pure abstract base class for root-finding algorithms.


[[Solver|classTrAnal_1_1Solver]] objects fit a set of values with a function and then extracts the nearest zero crossing value. These are used by the [[CFD|classCFD]] algorithms to locate zero crossings.
