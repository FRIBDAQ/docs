<a name="details"></a>## Detailed Description


SettingReader objects are able to take some source of DDAS Setings and turn them into a ModuleSettins struct. Derived classes could get this information from .set files, from the modules in a crate themselves or event from EPICS or a database. Note that an external entity must have initializd the API and read in the var files for this module (normally done in a [[CrateManager|classDDAS_1_1CrateManager]]).
