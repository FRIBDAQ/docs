<a name="details"></a>## Detailed Description


Reads a slot configuration for a [[structDDAS_1_1Crate]]. These look like e.g.:


```
*     <DDASCrate>
*      <slot number="2" />
*      slot number="5" />
*      slot number="6" />
*     </DDASCrate>
* 
```

The sample file below specifies there are modules in slots 2,5, and 6.
