<a name="details"></a>## Detailed Description


Provides a crate readerthat can read the module settings for a crate from a set file. Set files don't, by themselves, provide sufficient information to read them into a [[ModuleSettings|structDDAS_1_1ModuleSettings]] struct. In addtion we need the digitizer speed and a .VAR file that describes the layout of DSP Parameters in memory. These are per module items. The .set file, however is a per crate item...as we use it here.
