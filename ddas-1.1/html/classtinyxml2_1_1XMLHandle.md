<a name="details"></a>## Detailed Description


A [XMLHandle](https://github.com/FRIBDAQ/docs/tree/main/ddas-1.1/html/classtinyxml2_1_1XMLHandle.md) is a class that wraps a node pointer with null checks; this is an incredibly useful thing. Note that [XMLHandle](https://github.com/FRIBDAQ/docs/tree/main/ddas-1.1/html/classtinyxml2_1_1XMLHandle.md) is not part of the TinyXML-2 DOM structure. It is a separate utility class.


Take an example:

```
<Document>
        <Element attributeA = "valueA">
                <Child attributeB = "value1" />
                <Child attributeB = "value2" />
        </Element>
</Document>

```

Assuming you want the value of "attributeB" in the 2nd "Child" element, it's very easy to write a *lot* of code that looks like:


```
XMLElement* root = document.FirstChildElement( "Document" );
if ( root )
{
        XMLElement* element = root->FirstChildElement( "Element" );
        if ( element )
        {
                XMLElement* child = element->FirstChildElement( "Child" );
                if ( child )
                {
                        XMLElement* child2 = child->NextSiblingElement( "Child" );
                        if ( child2 )
                        {
                                // Finally do something useful.

```

And that doesn't even cover "else" cases. [XMLHandle](https://github.com/FRIBDAQ/docs/tree/main/ddas-1.1/html/classtinyxml2_1_1XMLHandle.md) addresses the verbosity of such code. A [XMLHandle](https://github.com/FRIBDAQ/docs/tree/main/ddas-1.1/html/classtinyxml2_1_1XMLHandle.md) checks for null pointers so it is perfectly safe and correct to use:


```
XMLHandle docHandle( &document );
XMLElement* child2 = docHandle.FirstChildElement( "Document" ).FirstChildElement( "Element" ).FirstChildElement().NextSiblingElement();
if ( child2 )
{
        // do something useful

```

Which is MUCH more concise and useful.


It is also safe to copy handles - internally they are nothing more than node pointers.

```
XMLHandle handleCopy = handle;

```

See also [XMLConstHandle](https://github.com/FRIBDAQ/docs/tree/main/ddas-1.1/html/classtinyxml2_1_1XMLConstHandle.md), which is the same as [XMLHandle](https://github.com/FRIBDAQ/docs/tree/main/ddas-1.1/html/classtinyxml2_1_1XMLHandle.md), but operates on const objects.
