<a name="details"></a>## Detailed Description


The [[structDAQ_1_1DDAS_1_1FirmwareConfiguration]] struct.


A simple structure to hold the paths to all firmware/settings files for a specific hardware type. These objects will be stored in a map of the [[classDAQ_1_1DDAS_1_1Configuration]] class and keyed by a hardware type.
