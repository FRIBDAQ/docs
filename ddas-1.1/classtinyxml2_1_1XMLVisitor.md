<a name="details"></a>## Detailed Description


Implements the interface to the "Visitor pattern" (see the Accept() method.) If you call the Accept() method, it requires being passed a [[XMLVisitor|https://github.com/FRIBDAQ/docs/tree/main/ddas-1.1/classtinyxml2_1_1XMLVisitor.md]] class to handle callbacks. For nodes that contain other nodes (Document, Element) you will get called with a VisitEnter/VisitExit pair. Nodes that are always leafs are simply called with [[Visit()|https://github.com/FRIBDAQ/docs/tree/main/ddas-1.1/classtinyxml2_1_1XMLVisitor.md#adc75bd459fc7ba8223b50f0616767f9a]].


If you return 'true' from a Visit method, recursive parsing will continue. If you return false, **no children of this node or its siblings** will be visited.


All flavors of Visit methods have a default implementation that returns 'true' (continue visiting). You need to only override methods that are interesting to you.


Generally Accept() is called on the [[XMLDocument|https://github.com/FRIBDAQ/docs/tree/main/ddas-1.1/classtinyxml2_1_1XMLDocument.md]], although all nodes support visiting.


You should never change the document from a callback.
