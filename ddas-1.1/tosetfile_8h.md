<a name="details"></a>## Detailed Description


The header file for the command line option parser generated by GNU Gengetopt version 2.22.6 [http://www.gnu.org/software/gengetopt](http://www.gnu.org/software/gengetopt). DO NOT modify this file, since it can be overwritten.


- Author
  GNU Gengetopt by Lorenzo Bettini
