<a name="details"></a>## Detailed Description


Reads a slot configuration for a [Crate](https://github.com/FRIBDAQ/docs/tree/main/ddas-1.1/structDDAS_1_1Crate.md). These look like e.g.:


```
*     <DDASCrate>
*      <slot number="2" />
*      slot number="5" />
*      slot number="6" />
*     </DDASCrate>
* 
```

The sample file below specifies there are modules in slots 2,5, and 6.
