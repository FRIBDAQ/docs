<a name="details"></a>## Detailed Description


Encapsulates data for ddas hits that may have fitted traces. This is produced by [[classDAQ_1_1DDAS_1_1FitHitUnpacker#a679b859096145c23ee82ceb728899eec]]. This is basically just a [[classDAQ_1_1DDAS_1_1DDASHit]] with extra fields.
