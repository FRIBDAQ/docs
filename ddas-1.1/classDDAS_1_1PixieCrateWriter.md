<a name="details"></a>## Detailed Description


[[Crate|structDDAS_1_1Crate]] writer that provides strategy methods to support writing a crate full of Pixie16 digitizers. This software uses a [[CrateManager|classDDAS_1_1CrateManager]] to ensure the API is initialized and that the digitizer DSP parameter address maps get loaded.
