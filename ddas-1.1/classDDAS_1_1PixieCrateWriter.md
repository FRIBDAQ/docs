<a name="details"></a>## Detailed Description


[Crate](https://github.com/FRIBDAQ/docs/tree/main/ddas-1.1/structDDAS_1_1Crate.md) writer that provides strategy methods to support writing a crate full of Pixie16 digitizers. This software uses a [CrateManager](https://github.com/FRIBDAQ/docs/tree/main/ddas-1.1/classDDAS_1_1CrateManager.md) to ensure the API is initialized and that the digitizer DSP parameter address maps get loaded.
