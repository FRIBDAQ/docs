# <a name="AEN103142"></a>marker

<a name="AEN103146"></a>## Name

marker -- Insert a 32 bit marker in the data

<a name="AEN103149"></a>## Synopsis

```
marker create name ?option value...?
marker config  name option value?..?
marker cget  name ?option?                
        
```

<a name="AEN103154"></a>## DESCRIPTION

This 'device' inserts a constant 32 bit value in the data. Note that
            the MVLC markers are 32 bit markers while the VMUSB markers are 16 bit
            markers.  There is only one option: `-value` the
            value of the marker inserted.   If this is not configured (not recommended), 
            a zero will be inserted.
