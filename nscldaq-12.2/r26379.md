# <a name="evb1_latesummary"></a>EVB_lateSummary

<a name="AEN26393"></a>## Name

EVB_lateSummary -- Widget to display summar of data late fragments.

<a name="AEN26396"></a>## Synopsis

**EVB::lateSummary *window ?options?*
**

** *$window* configure *options*
**

** *$window* cget *?option-name?*
**

<a name="AEN26408"></a>## DESCRIPTION

Provides a widget that can display a summary of data late cases.
            The widget contents are completely controlled by configuration
            options.  See OPTIONS below.

<a name="AEN26411"></a>## OPTIONS



- `-count`
  Sets the contents of the total late fragment count
                          field of the widget.
- `-worst`
  Sets the contents of the worst case timestamp difference
                          field of the widget.
