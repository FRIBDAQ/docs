# <a name="daq1.rdo_titleFromKv"></a>rdo_titleFromKv

<a name="AEN20830"></a>## Name

rdo_titleFromKv -- Set Readout Title From the KV 'title' Value.

<a name="AEN20833"></a>## Synopsis

**$DAQBIN/rdo_titleFromKv *mgr_host mgr_user readout_program*
**

<a name="AEN20837"></a>## DESCRIPTION

By convention the experiment title is maintained in the value of the
            title key of an experiment's key value store.
            This program:



- Fetches the program definition for the
                    *readout_program* program from the
                    manager running in *mgr_host* started by
                    the user *mgr_user*.  The assumption
                    is that this is a readout program that has the
                    ReadoutREST plugin running.
  The program definition describes the host in which this
                  Readout is running and its username will be the same as
                  *mgr_user*.  The REST service is
                  assumed to be running on the default service name.
- Fetches the value of the title  key from
                    the same manager.
- Requests that the specified Readout program set its title
                    to the value of the title key fetched from
                    the key value store.
