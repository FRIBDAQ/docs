# <a name="AEN102421"></a>sis3804

<a name="AEN102425"></a>## Name

sis3804 -- Create and configure SiS 3804 VME scaler modules

<a name="AEN102428"></a>## Synopsis

```
sis3804 create name ?option value?...
sis3804 config name ?option value?...
sis3804 cget name ?option?
        
```

<a name="AEN102433"></a>## DESCRIPTION

This command creates and manipulates the configurable options of
            an SIS3804 8 channel latching scaler module.

<a name="AEN102436"></a>## OPTIONS



`-base `*base-addresss*Sets the base address of the module. This must normally be specified.
                    The default value is 0 which is not usually useful.

`-refpulser ` *on | off*Enables or disables the reference pulser.  The reference pulser is
                 a 250MHz pulser which when enabled (on), pulses channel 1.  By default, this
                 is off (disabled).

`-disables ` *mask*Mask who's bits select which channels are disabled.  Bit 0 is channel 1,
                bit 2 is channel 2 and so on so, for example, a value of 5, disables channels
                1 and 3.

`-autoclear ` *on | off*If on, the default, the scaler is cleared after it has been read.
                    If not, the scaler is only cleared at the beginning of each run.
                    Note that the read and clear is atomic for each channel.  However,
                    any counts that come between the latch and read/clear will be lost.
