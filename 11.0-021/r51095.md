# <a name="ccusb3-cmodulecreator"></a>CModuleCreator

<a name="AEN51099"></a>## Name

CModuleCreator -- Object creational ABC for `CModuleFactory`

<a name="AEN51103"></a>## Synopsis

```
CModuleCreator
```

<a name="AEN51115"></a>## DESCRIPTION

`CModuleCreator` provides an abstract base class
            for module creators.  Module creators are objects that are
            registered with the
            [*CModuleFactory*](https://github.com/FRIBDAQ/docs/tree/main/11.0-021/r50998.md)
            singleton.  Objects that are instances of a concrete derivation from
            this class are matched up with object type names (used in the
            **Module create** command) and are responsible for
            creating objects of the specified type.

<a name="AEN51121"></a>## METHODS



- ` virtual  = 0 CControlHardware* operator()(std::string  name);`
  Pure virtual method that concrete classes must define/supply.
                          `name`  is the name of the item being
                          created by the **Module create** command
                          that caused this method to be called.
