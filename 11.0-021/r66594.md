# <a name="vmusb3-marker"></a>marker

<a name="AEN66606"></a>## Name

marker -- Insert a constant into the VMUSB data stream

<a name="AEN66609"></a>## Synopsis

**
marker create *name*
**

**
marker config *name -value uint16*
**

**
marker cget *name*
**

<a name="AEN66619"></a>## DESCRIPTION

When added to a stack, a marker inserts a constant 16 bit unsigned
            value in the outupt data produced by the VM-USB in response to that
            stack's trigger.

<a name="AEN66622"></a>## OPTIONS



- `-value` *uint16*
  The *uint16* unsigned 16 it
                          bit integer will be inserted into the output stream.
