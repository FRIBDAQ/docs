# <a name="AEN5091"></a>vmusb

<a name="AEN5095"></a>## Name

vmusb -- Provide access to the VMUSB scalers

<a name="AEN5098"></a>## Synopsis

**
vmusb create *name* ?*option value ...*?
                        **

**
vmusb config *name  option value ?...?*
**

**
vmusb cget *name ?option?*
**

<a name="AEN5109"></a>## DESCRIPTION

This command provides the ability to read the two 32 bit counters (scalers) in the
                        VMUSB module.  This contributes the following two 32 bit words to the event:

<a name="AEN5112"></a>+---------------------+  

|     Scaler A value  |  

+---------------------+  

|     Scaler B value  |  

+---------------------+

<a name="AEN5114"></a>## OPTIONS

The configuration options for he **vmusb** are:



- `-scalera ` *input-spec *
  Determines what increments scaler A.  This can be one of
                                  dgga, nimi1, and
                                  nimi2 dgga at present
                                  is not useful, but is provided in case, in the future, access
                                  to internal delay and gate generators is addeed.
- `-scalerb` * input-pec*
  Determines what increments scaler B.  This can be one of:
                                  carry, nimi1 or nimi2
                                  the carry  increments Scaler B when Scaler A overflows
                                  back to zero, effectively making the two 32 bit scalers a single 64 bit
                                  scaler with the Scaler B as the most significant bits.  Note that the
                                  readout order, in this case, is that of a little endian 64 bit number.
