# <a name="vmusb3-delay"></a>delay

<a name="AEN66068"></a>## Name

delay -- Insert a stack delay.

<a name="AEN66071"></a>## Synopsis

**delay create *name ?options...?*
**

**delay config *name option value ...*
**

**delay cget *name*
**

<a name="AEN66081"></a>## DESCRIPTION

This command creates a wait point in a stack.

<a name="AEN66084"></a>## OPTIONS



- **-value** *value*
  Defines the duration of delay in units of 200 ns.

<a name="AEN66093"></a>## EXAMPLES

<a name="AEN66095"></a>**Example 1. A simple delay example**

```
delay create delay0 -value 4 
         
```

Defines an 800 ns delay.
