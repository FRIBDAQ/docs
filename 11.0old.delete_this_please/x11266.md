# <a name="sbsrdo.sec.running"></a>57.6. Running a readout application

The readout application recognizes a few command options.
            The full Readout command reference is described in
            [Readout(1sbsReadout)](https://github.com/FRIBDAQ/docs/tree/main/11.0old.delete_this_please/r15826.md).
            You can get a summary of the options by invoking Readout with
            the `--help` option.
