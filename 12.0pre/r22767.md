# <a name="manpage.n568control"></a>n568Control

<a name="AEN22781"></a>## Name

n568Control -- GUI for the n568 shaper.

<a name="AEN22784"></a>## Synopsis

**n568Control.tcl *?configFile ...?*
**

<a name="AEN22788"></a>## DESCRIPTION

n568Control.tcl is a thin jacket around the
        [[n568Panel(3)|https://github.com/FRIBDAQ/docs/tree/main/12.0pre/r92223.md]]
        shaper control megawidget.  For each configuration file on the command
        line, a shaper control panel is created in a top-level window.
        The  format  of
       configuration files is described  in
       [[n568configfile(5)|https://github.com/FRIBDAQ/docs/tree/main/12.0pre/r99738.md]].

Since  the  jacket  program includes extensive online help menus,
       this man page will not describe how to
        operate the control panel.
