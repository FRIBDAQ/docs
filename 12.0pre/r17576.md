# <a name="AEN17576"></a>lg_lspeople

<a name="AEN17580"></a>## Name

lg_lspeople -- List the people defined in the logbook.

<a name="AEN17583"></a>## Synopsis

**
lg_lspeople
         **

<a name="AEN17586"></a>## DESCRIPTION

Provides a formatted list of the people that are known to the
            logbook e.g:

<a name="AEN17589"></a>```

$DAQBIN/lg_lspeople a b v
Salutation First Name Last Name
Mr         Ron        Fox
Prof.      Sean       Liddick
Dr.        Giordano   Cerizza
           Bryn       Forbes
Mr.        Tristan    Warmels

            
```
