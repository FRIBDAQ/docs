# <a name="AEN17989"></a>lg_lspeople

<a name="AEN17993"></a>## Name

lg_lspeople -- List the people defined in the logbook.

<a name="AEN17996"></a>## Synopsis

**
lg_lspeople
         **

<a name="AEN17999"></a>## DESCRIPTION

Provides a formatted list of the people that are known to the
            logbook e.g:

<a name="AEN18002"></a>```

$DAQBIN/lg_lspeople a b v
Salutation First Name Last Name
Mr         Ron        Fox
Prof.      Sean       Liddick
Dr.        Giordano   Cerizza
           Bryn       Forbes
Mr.        Tristan    Warmels

            
```
