# <a name="AEN17119"></a>lg_lspeople

<a name="AEN17123"></a>## Name

lg_lspeople -- List the people defined in the logbook.

<a name="AEN17126"></a>## Synopsis

**
lg_lspeople
         **

<a name="AEN17129"></a>## DESCRIPTION

Provides a formatted list of the people that are known to the
            logbook e.g:

<a name="AEN17132"></a>```

$DAQBIN/lg_lspeople a b v
Salutation First Name Last Name
Mr         Ron        Fox
Prof.      Sean       Liddick
Dr.        Giordano   Cerizza
           Bryn       Forbes
Mr.        Tristan    Warmels

            
```
