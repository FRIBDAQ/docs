# <a name="AEN17625"></a>lg_lspeople

<a name="AEN17629"></a>## Name

lg_lspeople -- List the people defined in the logbook.

<a name="AEN17632"></a>## Synopsis

**
lg_lspeople
         **

<a name="AEN17635"></a>## DESCRIPTION

Provides a formatted list of the people that are known to the
            logbook e.g:

<a name="AEN17638"></a>```

$DAQBIN/lg_lspeople a b v
Salutation First Name Last Name
Mr         Ron        Fox
Prof.      Sean       Liddick
Dr.        Giordano   Cerizza
           Bryn       Forbes
Mr.        Tristan    Warmels

            
```
