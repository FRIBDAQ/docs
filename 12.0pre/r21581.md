# <a name="evb1_deadsource"></a>EVB::deadsource

<a name="AEN21595"></a>## Name

EVB::deadsource -- Mark a data source dead.

<a name="AEN21598"></a>## Synopsis

**
EVB::deadsource *id*
**

<a name="AEN21602"></a>## DESCRIPTION

Marks the data source `id` dead.  From then on
            no fragments are expected from that source.
