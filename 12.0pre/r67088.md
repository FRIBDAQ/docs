# <a name="evb3_onend"></a>EVBC::onEnd

<a name="AEN67102"></a>## Name

EVBC::onEnd -- EZBuilder end run actions.

<a name="AEN67105"></a>## Synopsis

** **

<a name="AEN67108"></a>## DESCRIPTION

            proc.  This initiates a flush of the events queued.
