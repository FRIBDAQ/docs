# <a name="AEN1963"></a>start

<a name="AEN1967"></a>## Name

start -- start analysis from the current data source

<a name="AEN1970"></a>## Synopsis

**start**

<a name="AEN1973"></a>## DESCRIPTION

This command is not encapsulated.  It runs only in the
                    process in which it is invoked.  Since data source management
                    and data distribution are all done in the
                    MPI_ROOT_RANK and that has the interactive
                    interpreter as well, this is normally fine.
