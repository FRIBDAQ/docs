# <a name="AEN10591"></a>Chapter 55. The `Os` class

The `Os` class is a class that contains
        a few static methods that provide abstract interfaces to the underlying
        operating system.

To use this class, include the os.h header and link
        to libdaqshm.

See [[r40469]] for
        reference information that describes this class.
