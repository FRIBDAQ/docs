# <a name="tcl3.transientlabel"></a>TransientLabel

<a name="AEN83760"></a>## Name

TransientLabel -- Label widget that transforms to default.

<a name="AEN83763"></a>## Synopsis

**package require TransientLabel                                
                        **

**TransientLabel *path ?options?*
**

** *path*  configure *option value ?....?*
**

** *path*  cget *?option?*
**

<a name="AEN83777"></a>## DESCRIPTION

Provides a widget that allows you to set some transient text.
                After a specified timeout, the text modified reverts to some
                default text.  This can be useful when a label normally showing
                some fixed information doubles as a status line.  The status
                information can then be displayed for some fixed amount of time
                before the label reverts to its normal function.

<a name="AEN83780"></a>## OPTIONS



- `-defaultstring`
  Option that containns the value of the
                                          'normal' string.
- `-timerlength`
  Numbrer of milliseconds for which the
                                          transient text will be displayed before
                                          the text reverst to the
                                          `-defaultstring`
- `-text`
  The transient text to display for the
                                          `-timerlength` milliseconds.
