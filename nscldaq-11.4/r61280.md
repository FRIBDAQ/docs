# <a name="evb3_starts800source"></a>EVBC::startS800Source

<a name="AEN61294"></a>## Name

EVBC::startS800Source -- Start S800 data source

<a name="AEN61297"></a>## Synopsis

**
EVBC::startS800Source *ring-uri source-id ?info?*
**

<a name="AEN61301"></a>## DESCRIPTION

Please use the [*EVBC::registerRingSource*](https://github.com/FRIBDAQ/docs/tree/main/nscldaq-11.4/r61134.md) instead of this proc.

This is actually a wrapper for a call to
            **EVBC::startRingSource** using a timestamp
            extractor built for S800 data.  The parameters have the same
            meaning as for **EVBC::startRingSource**.  If the
            `info` parameters is not supplied it defaults
            to S800 USB data.
