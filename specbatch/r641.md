# <a name="AEN641"></a>analysissink

<a name="AEN645"></a>## Name

analysissink -- Establish a data distributor to the anlaysis pipeline

<a name="AEN648"></a>## Synopsis

**package require spectcl**

**analysissink**

<a name="AEN653"></a>## DESCRIPTION

Sets the data distributor to an analysis sink.  Regardless
                        of where the data comes from, it will be passed on to the
                        analysis pipeline for histogramming.
