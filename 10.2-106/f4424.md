# <a name="AEN4424"></a>Preface

The pages below provide reference material for the EZBuilder
        layer of software.  Conceptually, this layer provides a single
        initialization proc (called from **OnStart**),
        a proc to call from **OnBegin** and another proc to call
        from **OnEnd**.
