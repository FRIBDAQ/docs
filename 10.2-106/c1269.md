# <a name="chapter.scalerdisplay"></a>Chapter 23. Scaler Display Software.

The scaler display software consists of two components:



- [[sclclient|https://github.com/FRIBDAQ/docs/tree/main/10.2-106/r8051.md]]
  Connects to the NSCL data acquisition system buffer manager
                          and accepts scaler and run state-change buffers.  The software
                          connects to a
                          [[tclserver|https://github.com/FRIBDAQ/docs/tree/main/10.2-106/r10588.md]]
                          application and maintains a set of Tcl variables in that server
                          that describe instantaneous and continuous scaler state.
- [[ScalerDisplay|https://github.com/FRIBDAQ/docs/tree/main/10.2-106/r10722.md]]
  A script that starts up a
                          [[tclserver|https://github.com/FRIBDAQ/docs/tree/main/10.2-106/r10588.md]] that runs a script
                          which takes the variables maintained by
                          [[sclclient|https://github.com/FRIBDAQ/docs/tree/main/10.2-106/r8051.md]], a configuration file
                          and produces a scaler display.
