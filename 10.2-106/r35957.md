# <a name="cmmaperror"></a>CMmapError

<a name="AEN35961"></a>## Name

CMmapError -- Report errors in memory mapping requests.

<a name="AEN35964"></a>## Synopsis

```

#include <MmapError.h>
         
```

```

  CMmapError(const char* pDoing);
```

<a name="AEN36007"></a>## Description

This class is an exception that can be thrown by the
            `CVMEInterface::Map` method.  It is derived
            from the [`CException`](https://github.com/FRIBDAQ/docs/tree/main/10.2-106/r12452.md)
            class.  See that page for full documentation on exception objects.
