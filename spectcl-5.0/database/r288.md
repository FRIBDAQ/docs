# <a name="AEN288"></a>dbconfig::restoreAllSpectrumContents

<a name="AEN292"></a>## Name

dbconfig::restoreAllSpectrumContents -- Restore all spectrum contents from a save set

<a name="AEN295"></a>## Synopsis

**package require dbconfig
                    **   
**sqlite3 *db some-file*
**   
**dbconfig::restoreAllSpectrumContents *db save-set*
**

<a name="AEN302"></a>## DESCRIPTION

This command restores the contents of all
                        spectra that were saved in the named save set.
                        Depending on the quantity of data, this can
                        take a significant amount of time.

`db` is the
                        database connection command established via the
                        **sqlite3** command.
                        `save-set` is the name
                        of the save-set to restore from.
