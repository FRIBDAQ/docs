# <a name="AEN392"></a>dbconfig::hasRun

<a name="AEN396"></a>## Name

dbconfig::hasRun -- Determin if a saveset has a run

<a name="AEN399"></a>## Synopsis

**
package require dbconfig
                    **   
**
sqlite3 *db db-filename*
**   
**
dbconfig::hasRun *db saveset-id*
**

<a name="AEN406"></a>## DESCRIPTION

**dbconfig::hasRun** returns true if the
                    the save set with id `saveset-id`
                    has an associated run containing events in the database
                    attached with the command `db`.
                    Note the `saveset-id` is not the
                    name of the saveset, it's the value returned from
                    **dbconfig::saveConfig**.  It is also the
                    dict key id in the list of configurations
                    returned from **dbconfig::listConfigs**.

<a name="AEN416"></a>## EXAMPLES

<a name="AEN418"></a>```

sqlite3 db configs.db
...
foreach config [dbconfig::listConfigs db] {
    puts -nonewline "Configuration : [dict get $config name] : "
    if {[dbconfig::hasRun db [dict get $config id]]} {
        puts "has events associated with it."
    } else {
        puts "has no nevents associated with it."
    }
}
                    
```

This scripts lists all the configurations in the database
                    and informs the user if there are or are not events
                    associated with the configuration.
