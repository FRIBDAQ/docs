3.3. Other parameters

There are two other parameters the data source needs to have set. These arise from the need to couple event fragments from GET with fragments from other data sources (GET or otherwise).

Data from each source sent to the event builder must have

  • A unique source id that identifies which subsystem produced the event.

  • A timestamp that is used to define coincideces for the sake of gluing events togehter into events.

Note that depending on whether or not a clock source is provided to the CoBo, the timestamp may or may not be substituted for with the event number.

Timesstamp source

Determines what the datarouter puts into the ring item's timestamp field. Normally, the default of timestamp is correct, however if there is no external clock source, this can be set to trigger_number instead.

Soource id:

Specifie the desired source id.

Note that these parameters have significance for the data router and downstream software involved in event building and untangling data from event built events.
