Chapter 1. Introduction

This document describes how to use the interface software that allows single CoBo GET systems to interface to the NSCL data acquisition system. The document is organized as follows:

  1. S800 Quickstart Provides a quick start cookbook for adding the S800 GET CRDC data source to an experiment.

  2. How this all works Provides an orientation to GET and how it is interfaced to the NSCLDAQ.

  3. Interface components. describes each component used to interface GET to the NSCLDAQ and provides reference manual pages for them.
